# دهانات وديكورات — GitHub APK Builder

## بناء APK بدون Android Studio

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى المستودع.
3. افتح تبويب **Actions**.
4. اختر **Build Android APK**.
5. اضغط **Run workflow**.
6. انتظر حتى تصبح العملية ناجحة.
7. افتح نتيجة التشغيل وانزل إلى **Artifacts**.
8. حمّل `DahanatDecor-debug-apk`، ثم فك الضغط لتحصل على `app-debug.apk`.
9. انقل APK إلى هاتف Android وثبّته.

هذه نسخة Debug للتجربة وليست إصدار Google Play النهائي.
